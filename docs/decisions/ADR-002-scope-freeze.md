# ADR-002: Freeze everything outside the core loop

**Status.** Accepted 2026-09-08. Confirmed and amended 2026-09-09 (see the amendment below).

**Context.** The repository contains about 120,000 lines, of which roughly 40,000 implement subsystems with no user: team agents, pipelines, worktree fleets, delegation, fleet policy and SIEM export, a desktop daemon, accounts, billing, a cloud relay, push notifications, mDNS discovery. Most were generated by an unattended orchestration loop between 16 and 18 August 2026 on top of a Claude Code adapter that did not work. The market research (`docs/product/positioning.md`) shows GitHub, Anthropic and OpenAI ship the enterprise and cloud pieces natively.

**Decision.** The launch scope is the core loop only: pair, project, thread, Claude Code with the approval gate, transcript, terminal, Changes, resume. The other subsystems stay in the tree (their tests pass and removal would bloat the launch diff) but are hidden from primary navigation, absent from marketing, and not extended. Their disposition is decided per subsystem in ADR-005, after the first-users experiment.

**Consequences.** Smaller surface to secure and document; a landing page that tells the truth; a roadmap that starts from what works. Cost: the tree still carries code that new contributors must be told to ignore (`CLAUDE.md` lists it).

---

**Amended 2026-09-09.** This ADR originally implied that the frozen subsystems were probably worthless and should move to an archive branch within a month. That conflated two different things: *not in the MVP* and *not valuable*. Delegation and pipelines are the existing implementations of hypotheses H3 (parallelism) and H6 (automation), which the first-users experiment is specifically designed to test. Freezing them remains correct as sequencing. Deleting them on a schedule, before the experiment reports, would throw away the payoff of a positive answer.

The disposition of each subsystem — keep, freeze pending evidence, or delete — is now decided per subsystem in `docs/decisions/ADR-005-frozen-code-disposition.md`, and the archive decision waits for the Phase 2 report rather than a calendar.
